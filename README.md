# Gomuko-Py2 (Python, vs computer)

Gomoku (five in a row) in the Python console where you play against the computer.

## How to play

You enter the board size, the player names and symbols, and the win length. Then you take turns with the computer by entering a row and column. The first to connect the win length in a row wins.

## Run

```bash
python gomukopythonvsAI.py
```

Python 3 is required. There are no other dependencies.
